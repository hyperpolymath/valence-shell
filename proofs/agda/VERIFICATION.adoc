== The two rejections, verbatim

[source]
----
FilesystemModel.agda:179,3-38
Cannot postulate funext with safe flag
when scope checking the declaration
  funext : Extensionality lzero lzero
----

[source]
----
FilesystemModel.agda:155,11-15
I'm not sure if there should be a case for the constructor refl,
because I get stuck when trying to solve the following unification
problems (inferred index ≟ expected index):
  p ≟ p
Possible reason why unification failed:
  Cannot eliminate reflexive equation p = p of type List String
  because K has been disabled.
----

The first is `postulate funext` in `FilesystemModel`. The second is *not* about
`funext`: any case split on `Dec (p ≡ p)` needs K, because Agda cannot eliminate
the reflexive equation on `List String` without it. Every `... | yes refl` clause
over `p path-≟ p` depends on that, so removing the postulate alone would not make
`--without-K` pass.

== Status and waiver

* Status under PROOF-POLICY §5: `proven-with-postulates`.
* Status under mathesis §5: *Claimed / reproduced*, **not** grade 3.
* Waiver: this artefact is checked with the unflagged `agda` invocation because the
  two blockers above are proof-engineering work, not documentation work. The waiver
  expires when either (a) `funext` is discharged (state whole-filesystem
  reversibility pointwise, or move the tree to a `--cubical` build), or (b) the path
  decision is threaded through the operations instead of being re-asked with
  `p ≟ p` at each site. Until then, no claim in this repository may say the Agda
  layer is checked under `--safe --without-K --cubical-compatible`.
