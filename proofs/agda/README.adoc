= proofs/agda/ — Agda Filesystem Proofs (Intensional Type Theory)

Agda (intensional dependent type theory) cross-validates the
filesystem reversibility theorems against the primary Lean 4 source
of truth (`../lean4/`). Agda's intensional treatment of equality
provides a different lens than Lean's HoTT-flavoured framework.

== Files

[cols="2,4"]
|===
| File | Role

| `FilesystemModel.agda`        | Core `Filesystem` model + structural lemmas.
| `FilesystemComposition.agda`  | Composition theorems.
| `FilesystemEquivalence.agda`  | State-equivalence relations.
| `FileOperations.agda`         | Per-op specs (mkdir, rmdir, touch, rm).
| `FileContentOperations.agda`  | Read/write/append + size lemmas.
| `CopyMoveOperations.agda`     | `cp`/`mv` reversibility.
| `PermissionOperations.agda`   | chmod/chown bit-preservation.
| `SymlinkOperations.agda`      | Symlink creation + traversal.
| `RMOOperations.agda`          | Remove-Match-Obliterate (GDPR-relevant).
|===

Manifest:

* `valence-shell.agda-lib` — Agda library file declaring this
  directory as the `valence-shell` library.

== Build

```bash
cd proofs/agda
agda --library-file=<stdlib>.agda-lib --library=valence-shell FilesystemModel.agda    # single module
agda --library-file=<stdlib>.agda-lib --library=valence-shell CopyMoveOperations.agda # transitive
```

All nine modules type-check this way under Agda 2.6.4.3 + stdlib 2.1.1 and under
Agda 2.7.0.1 + stdlib 2.2.

*Waiver (see `VERIFICATION.adoc`).* The estate invocation is
`agda --safe --without-K --cubical-compatible`, and this tree does **not** meet
it: `--safe` reports `Cannot postulate funext with safe flag` and `--without-K`
reports `Cannot eliminate reflexive equation p = p of type List String because K
has been disabled`. The commands above are therefore the *unflagged* invocation,
used under a recorded waiver. Do not add `--safe` or `--without-K` to them until
those two obstacles are discharged.

== Conventions

* Status under PROOF-POLICY §5 is `proven-with-postulates` (one postulate:
  `funext` in `FilesystemModel`) -- the waiver above is why it is not `proven`.
* PascalCase module names; one module per file.
* No `.agdai` interface artefacts in tree (cached locally, not committed).
