= proofs/agda/ — Agda Filesystem Proofs (Intensional Type Theory)

Agda is the theory source of truth for the filesystem reversibility
theorems (owner ruling 2026-11-09, per `standards` PROOF-POLICY §1). The Lean 4
(`../lean4/`) and Rocq (`../coq/`) trees are recheck legs.

== Files

[cols="2,4"]
|===
| File | Role

| `FilesystemModel.agda`        | Core `Filesystem` model + structural lemmas.
| `FilesystemComposition.agda`  | Composition theorems.
| `FilesystemEquivalence.agda`  | State-equivalence relations.
| `FileOperations.agda`         | Per-op specs (mkdir, rmdir, touch, rm).
| `FileContentOperations.agda`  | Read/write/append + size lemmas.
| `CopyMoveOperations.agda`     | `cp`/`mv` reversibility.
| `PermissionOperations.agda`   | chmod/chown bit-preservation.
| `SymlinkOperations.agda`      | Symlink creation + traversal.
| `RMOOperations.agda`          | Remove-Match-Obliterate (GDPR-relevant).
| `PreconditionWitnesses.agda` | One inhabitant per operation precondition (non-vacuity).
| `All.agda`                   | Imports every module; the file CI checks.
|===

Manifest:

* `valence-shell.agda-lib` — Agda library file declaring this
  directory as the `valence-shell` library.

== Build

`valence-shell.agda-lib` depends on `standard-library`, so Agda must know where
agda-stdlib v2.2 lives. Register it once (CI does the same):

```bash
git clone --depth 1 --branch v2.2 https://github.com/agda/agda-stdlib.git ~/agda-stdlib
mkdir -p ~/.agda
echo ~/agda-stdlib/standard-library.agda-lib >> ~/.agda/libraries
```

Then check every module:

```bash
cd proofs/agda
agda --safe --without-K --cubical-compatible All.agda
```

This is the estate invocation (PROOF-POLICY §2.1). It checks all ten modules
under Agda 2.7.0.1 + agda-stdlib v2.2; CI runs the same command
(`.github/workflows/agda.yml`). See `VERIFICATION.adoc` for the receipt.

== Conventions

* Status under PROOF-POLICY §5 is `PROVEN`: no postulates, no escape pragmas.
* Filesystem equality is pointwise (`_≗_`), so no function extensionality is
  needed.
* PascalCase module names; one module per file.
* No `.agdai` interface artefacts in tree (cached locally, not committed).
