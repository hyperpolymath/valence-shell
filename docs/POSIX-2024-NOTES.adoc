=== Overview

POSIX.1-2024 (Issue 8) was published in June 2024, replacing
POSIX.1-2017 (Issue 7). This document tracks which POSIX 2024 changes
are relevant to valence-shell and our current compatibility status.

=== Relevant POSIX 2024 Changes

=== Priority for vsh

POSIX 2024 changes that should be tracked as vsh approaches v1.0:

[arabic]
. *`+local+` builtin* — now standardized; implement alongside shell
functions (M12)
. *`+pipefail+`* — valuable for robust scripting; implement after
pipelines are solid
. *`+${param@operator}+`* — useful but lower priority than functions and
scripts
. *`+trap+`* — essential for any script-capable shell; implement in M11
builtin expansion
. *Signal handling clarifications* — align with POSIX 2024 once
`+trap+`/SIGCHLD land

=== Notes

* vsh already implements several features that remain non-POSIX even in
Issue 8 (here-strings `+<<<+`, `+[[ ]]+`, process substitution, brace
expansion). These are kept as extensions.
* The formal verification strategy is orthogonal to POSIX compliance
level; reversibility proofs apply regardless of which POSIX edition is
targeted.
* Full POSIX 2024 compliance requires completing milestones M10-M14
first (see `+docs/POSIX_COMPLIANCE.md+`).
