[[idris]]
== Idris2 `believe_me`: experiment

Goal: prove `(s : String) -> (s == s) = True` without an axiom.

* Direct `Refl` fails under Idris2 0.8.0: "Can't solve constraint between:
  True and intToBool (prim__eq_String s s)". The primitive does not reduce
  on a variable.
* Going through `decEq s s` fails with the same constraint. Idris2's own
  `DecEq String` (`libs/base/Decidable/Equality.idr`, `primitiveEq`) is
  itself `believe_me`, so routing through it would move the axiom into the
  standard library, out of the scanner's sight, without removing it.
* Removing it for real means changing path components from `String` to a type
  with structural equality, which changes the ABI-facing model.

Outcome: `axStringEqRefl` and `axBits8EqRefl` stay as the two registered
axioms (`.machine_readable/IDRIS2_AXIOMS.a2ml`, gated by
`.github/scripts/check-idris2-believe-me.sh`), with an inline Hypatia
allow that names both. The package builds and the gate passes.
