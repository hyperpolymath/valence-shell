== 1. Summary

* *One real soundness defect was found and is fixed in this change.* In Lean,
  `RmdirPrecondition` was uninhabited: `isEmptyDir` quantified over ancestors
  (`child.isPrefixOf p`) instead of descendants, and the parent always exists.
  Every Lean theorem with that hypothesis was vacuous. That covers
  `rmdir_removes_path`, `rmdir_mkdir_reversible`, `rmdirPreservesEquiv`, and,
  through `reversible (.mkdirOp p)`, which needs `RmdirPrecondition` after the
  mkdir, every composition theorem on a sequence containing mkdir or rmdir. The
  Rocq/Coq and Isabelle definitions have the correct direction. Section 3.1 has
  the evidence.
* *No theory theorem in this repository reaches `PWG-3`.* The Agda tree does
  not check under the §2.1 invocation (`--safe --without-K
  --cubical-compatible`), because of the `funext` postulate. By §8, every theory
  theorem here is `ungraded`. The census: 0 of 9 Agda modules check under §2.1,
  so 0 theorems are at `PWG-3` or better.
* The existing Lean and Coq proofs are *target-only evidence* under §3, because
  no Agda proof is yet `PROVEN`, so the statements cannot be compared. Their
  correspondence state is `AGDA-PENDING` (§2.2).
* The Z3 leg is `ASSUMED` at best (§5: a direct SMT run with no certificate),
  and two of its five files prove nothing.
* Idris2 (the engineering/ABI leg, §1) builds under `--total`:
  `PROVEN-WITH-AXIOMS`, with the 2 registered primitive-equality axioms.
* The Rust suite is green: 827 passed, 0 failed, 15 ignored, across 23 test
  binaries. No Creusot, Pearlite or Verus contract exists yet (§1.2), so the Rust
  implementation leg is `OPEN`.
* The merged route plan disagrees with the policy in six places (section 5).
  Those need owner rulings before the implementation session starts.

=== 3.1 The Lean `RmdirPrecondition` defect

Before this change:

[source,lean]
----
def isEmptyDir (p : Path) (fs : Filesystem) : Prop :=
  isDirectory p fs ∧
  ∀ child : Path, child.isPrefixOf p → child ≠ p → ¬pathExists child fs
----

`parentPath p` is a proper prefix of `p` and, by the `parentWritable` field, it
exists. The following theorem was checked against the unfixed file under Lean
4.34.1 (axioms: `propext`, `Classical.choice`, `Quot.sound`):

[source,lean]
----
theorem rmdir_precondition_uninhabited (p : Path) (fs : Filesystem) :
    ¬ RmdirPrecondition p fs
----

The fix flips the prefix test to `p.isPrefixOf child`. The Coq
(`path_prefix p child`) and Isabelle (`prefix p child`) models already had this
direction. After the fix:

* All 8 Lean libraries that built before still build, and so does
  `model_oracle`. No proof depended on the vacuity. Two of the affected theorems
  (`rmdir_removes_path`, `rmdir_mkdir_reversible`) never used the hypothesis;
  they were true but could not be applied to any state.
* The uninhabitedness proof no longer typechecks.
* The new library `PreconditionWitnesses` exhibits an inhabitant of every
  precondition (mkdir, rmdir, createFile, deleteFile, symlink) and of
  `reversible (.mkdirOp ["a"]) emptyFS`. Its axioms are `propext` and
  `Quot.sound` at most. A future edit that empties a precondition now fails the
  build.

=== 3.2 Related findings, not fixed here

* *CI built almost none of the Lean tree.* `rust-cli.yml` ran a bare
  `lake build`, which builds only the default target (`FilesystemModel`), and
  `lean-verification.yml` builds only `Extraction` and `model_oracle`. This
  change makes `rust-cli.yml` build the 8 working libraries plus
  `PreconditionWitnesses` by name.
* *The extracted model does not check emptiness.* `Extraction.isEmptyDirBool`
  is "simplified: just check if it's a directory", and no theorem links it to
  `isEmptyDir`. The Lean oracle that the Rust differential tests drive therefore
  allows rmdir of a non-empty directory. This is a spec/executable gap at the
  oracle seam.
* *Agda `IsEmptyDir` is a stub* (see the table). Removing `funext` (route plan
  P5) should also complete this record.
* *Three Idris2 holes sit outside the proof ledger.* The mathesis hole scanner
  (`scripts/census/proof-holes.sh`) finds `?fieldsAlignedProof`,
  `?exampleFieldsAligned` and `?offsetInBoundsProof` in
  `alkahest-shell-transmuter/src/abi/Layout.idr` (lines 140, 161, 178).
  `PROOF-NEEDS.adoc` and `CLAUDE.md` count only `proofs/idris2/`, so they report
  zero Idris2 holes. `offsetInBounds` is also unprovable as stated: it quantifies
  over every `Field`, not only the fields of the layout.
* *The census and the ledger classify `believe_me` differently.* mathesis counts
  the 2 registered primitive-equality axioms as `hole`; this repo registers them
  as axioms. Its row today reads axioms 1 (Agda `funext`), holes 5 (those 3 plus
  the 2 `believe_me`), policy 9 (Agda files without `--safe`). A local scan of this
  branch gives the same counts, so this change leaves the row as it is.
* *Mizar proofs look unfinished.* For example
  `copy_move_operations.miz:200-201` discharges a reversibility equation with
  `by A1`, the bare precondition. This cannot be confirmed without running the
  checker.
